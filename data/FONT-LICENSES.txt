================================================================================
CHIPMACHINE - FONT ATTRIBUTION AND LICENSES
================================================================================

ChipMachine bundles the font files listed below. This file records each font's
author and license, and reproduces in full the text of the SIL Open Font
License, Version 1.1, which governs several of them.

Audited 2026-07-29. Licenses were read from each file's embedded OpenType
`name` table (copyright / license / license-URL / designer records) and
cross-checked against the distributor's own stated terms.

Typography reaches the screen by two routes, and both are covered here:
font files under data/ (sections 1-2), and one glyph atlas compiled into the
executable (section 3). The build embeds no font files -- a scan of the linked
binary finds no sfnt/WOFF payload and none of the name strings that vendored
fonts (ProggyClean, Vera, DejaVu, Roboto, Font Awesome, JUCE, Dear ImGui) would
leave behind. Fonts under external/ belong to vendored upstream projects and are
not copied into the bundle by package_app.sh.

Contents:
  1. User-interface font (SIL OFL 1.1)
  2. Scroller fonts (data/fontsmainscroll)
  3. Glyph atlas compiled into the executable
  4. Full text of the SIL Open Font License, Version 1.1

NOTES
--------------------------------------------------------------------------------
No bundled font is awaiting license review. Every file in sections 1-2 is either
OFL-licensed or released by its author as free for commercial use.

Four fonts previously bundled here were removed on 2026-07-29 for lack of
demonstrable redistribution rights, and must not be re-added:

  * Neutra.otf  -- Neutra Text SC Alt Bold, House Industries / Brand Design Co.
                   (c) 2002, designed by Christian Schwartz. Proprietary retail
                   font from the Neutraface collection; the House Industries
                   desktop license does not cover redistributing the font file
                   inside an application bundle. Replaced as the UI font by
                   Alegreya Sans SC Bold (section 1), chosen because it is
                   likewise a true small-caps design, so the caps-only
                   appearance and the layout that depends on it were preserved.
  * Bello.otf   -- Bello SmCp, Underware (c) 2004. Proprietary retail font;
                   application embedding requires a purchased license
                   extension.
  * Blunder.otf -- Blunder, 3wprotype (I Wayan Wisna Wijaya). The file carried
                   no copyright, designer or license record of any kind, and
                   the font is sold commercially by its publisher.
  * Krisha (Regular).otf
                -- Krisha, Daler Mukhiddinov (c) 2019, dalerms.com. The file
                   carried no license record ("All rights reserved"). The font
                   circulates as a free release, but published accounts of its
                   terms conflict -- some state SIL OFL / free for commercial
                   use, others personal use only -- and the original download
                   source could not be established. Removed rather than shipped
                   on an unresolved claim.

Because the scroller loads every .otf in data/fontsmainscroll without an
allowlist, any font dropped into that folder ships with the application. Add a
font here only after recording its license in this file.

3. GLYPH ATLAS COMPILED INTO THE EXECUTABLE
================================================================================

external/apone/mods/grappix/grappix/staticfont.h
  Symbol:    `static_font` (texture_font2_t)
  Contents:  A 128x128 single-channel distance-field atlas holding 95 glyphs
             (the printable ASCII range), plus their metrics and kerning. This
             is a rasterised bitmap, not a font file -- which is why it does not
             appear in any search for .ttf/.otf files.
  Source:    Generated by the `makefont` tool of Freetype GL
             (Copyright 2011, 2012 Nicolas P. Rougier, 2-clause BSD; the file
             retains that notice in its header). Vendored via the apone
             dependency.
  Typeface:  Not recorded anywhere in the file. Rendering the atlas shows a
             light humanist sans consistent with Bitstream Vera Sans, which is
             the typeface Freetype GL's own demos and makefont examples use.
             Bitstream Vera is freely redistributable under the Bitstream Vera
             Fonts Copyright; its only substantive restrictions are on selling
             the font software by itself and on reusing the "Bitstream Vera"
             name for modified versions, neither of which a bitmap atlas
             engages. Treated as free to redistribute on that basis, with the
             identification recorded here as probable rather than confirmed.
  Reached by: Font::Font(bool) builds a font from this atlas, and Font::covers()
             and the text builder fall back to it whenever `ref->font` is null.
             Nothing constructs Font(true) directly, but grappix::Font's default
             constructor leaves `ref` null, and ChipMachine's `font` / `listFont`
             members (ChipMachine.h) are default-constructed and only assigned a
             real font if findFile() locates one (ChipMachine_config.cpp). So the
             atlas is the live fallback if data/AlegreyaSansSC-Bold.ttf is
             missing at runtime; in a correctly packaged build it never renders.
