## Considerations

* ZIP archives can be up to 15MB
* ZIP archives are for the games and contain VGM files with music from the game and screenshot
* It could be the best to download the ZIP archive, extract and then form the multi-song format for the player to show just one entry in the search results
* there are about 4.5K games in the list
