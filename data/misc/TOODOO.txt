*************************************************

* VGMRips
URL: [https://vgmrips.net](https://vgmrips.net)
What it is: The premier home for .vgm (Video Game Music) file logs, focusing heavily on arcade boards (Capcom CPS1/2/3, Sega system 16, Neo Geo) and sound chips like the YM2612, YM2151, and AY-3-8910.
VGMRips (Use the Server Admin's Zip)
The Reality: VGMRips is a database front-end. Scraping individual pages for .vgm packs will get your IP blocked. The former server host maintains an official, all-in-one compressed file.
Go directly to the VGMRips forum thread: https://vgmrips.net/forum/viewtopic.php?t=496
The thread is titled "VGMRips full download packs".
Download the single aggregated zip file (VGMRips_all_of_them_[DATE].zip). It sits around 4 to 5 GB and contains every single pack logged on the site up to its compilation date.

* Project 2612 & SMS Power!
URLs: [https://project2612.org](https://project2612.org) | [https://www.smspower.org](https://www.smspower.org)
What they are: Definitive, dedicated system vaults. Project 2612 is the definitive source for Sega Genesis/Mega Drive .vgm rips. SMS Power handles Sega Master System, Game Gear, and SG-1000 audio logging.
These sites are simple, predictable directory trees. They do not block standard command-line tools if you throttle your requests.
Project 2612 (Sega Genesis)
Use wget to cleanly mirror the entire structured .vgm archive directory. Use a mirror flag, reject HTML files, and add a mandatory delay to avoid triggering server alerts:
Bash
wget --mirror --no-parent --no-host-directories \
     --reject "index.html*" --wait=1 --random-wait \
     https://project2612.org/vgm/
SMS Power! (Sega Master System / Game Gear)
SMS Power hosts pre-packaged zip files of their entire music section.
Bash
wget --mirror --no-parent --accept "*.zip" \
     --wait=1 --random-wait \
     https://www.smspower.org/Music/

* Mirsoft World of Game Mods
URL: [http://www.mirsoft.info](http://www.mirsoft.info)
What it is: A massive database specifically tracking down original game tracker modules across PC, Amiga, and Atari platforms.

* https://zxtunes.com -- a Russian site
A massive historical repository of ZX Spectrum chiptunes. While heavily populated by standard AY tracking formats, its index includes extensive mappings of older, undocumented internal-beeper game routines that were ripped and isolated by early scene groups.

* GYUSYABU PC-98 SOUNDTRACKS
  - URL: http://gyusyabu.ddo.jp (or mirrors)
  - Platforms/Chips: NEC PC-9801/8801 FM Synthesis
  - Key Formats: High-quality .mp3 rips
  - Notes: A long-standing Japanese community archive hosting pre-recorded MP3 renders
    of PC-98 game music recorded from real hardware (PC-9821 with OPNA boards).

* KHINSIDER VIDEO GAME MUSIC
  - URL: https://downloads.khinsider.com
  - Platforms: All gaming platforms (modern & retro)
  - Key Formats: Pre-rendered (.mp3, .flac)
  - Notes: Contains pre-recorded soundtracks (OSTs) for consoles that are hard to
    emulate or rely on streamed audio (e.g. CD-DA, ADX). Scrapers / bulk-downloaders exist.

* SITTING ON CLOUDS
  - URL: https://www.sittingonclouds.net
  - Platforms: Modern consoles, arcade systems
  - Key Formats: Pre-rendered (.mp3, .flac)
  - Notes: High-quality FLAC and MP3 game soundtrack index. Useful as a fallback
    for games where native chips cannot be easily emulated (e.g. modern Arcade/PS3/PS4).
