# mirsoft.info

## Base download link

`http://mirsoft.info/gamemods/`
`http://mirsoft.info/gamemods/<GAME_NAME>.zip`
`http://mirsoft.info/gamemods/MacPuyo.zip`

## ZIP content

* the archive name is the game name (needs to be URL encoded for download)
* multiple music files (.mod .xm .s3m etc)
* one or more text files with game info
* largest archive is about 50MB
