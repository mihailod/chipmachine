What it is: Pouet is great for comments and quick links, but Demozoo is the modern, highly structured relational database for the demoscene. It maps productions, groups, parties, and specific scene musicians across all platforms (including retro and modern PC).
Demozoo is a highly structured database. Scraping the raw HTML pages is a waste of time and parsing energy. They provide a completely open, fully documented JSON API for bulk data synchronization.
API Base: https://demozoo.org/api/v1/
To extract all demoscene music production links programmatically, loop through the productions endpoint filtering by the music type:
Bash
curl -H "Accept: application/json" "https://demozoo.org/api/v1/productions/?production_type=music"
Iterate through the paginated JSON responses to extract data fields natively instead of writing brittle regex scrapers.
