# Zophar Music Database

## Music File List
list.csv

### Columns
```
"name","image_url","game_page_url","release_date","console","developer","publisher","l1","l2","l1_url","l2_url"
```

* l1 - Link one header, explains if the archive is of MP3 or original music. Also states the size of the ZIP archive
* l2 - Link two header, explains if the archive is of MP3 or original music. Also states the size of the ZIP archive

* game_page_url - can be used to scrap links to the individual files from the archive. It only offers links to the MPS versions
