# DefleMask .dmf songs the clean-room dmfcrplugin can play -- one collection
# path per line (modland-relative for the Deflemask/ corpus, full URL for
# Battle of the Bits). Used ONLY by the Mac App Store build, which has no
# Furnace and therefore no other .dmf decoder.
#
# This is an ALLOW-list, the inverse of csid_silent_sids.txt: a "Deflemask" /
# "DefleMask" row is kept in the mas index only if it appears here. That is
# needed because the format column is chip-target-agnostic -- it says
# "Deflemask", not which of the eight DefleMask systems the file targets -- and
# dmfcrplugin covers SEGA Genesis and SEGA Master System only. Keying the gate
# on the format name alone would resurface all 2,071 rows, most of which mas
# still cannot play.
#
# MEASURED, not assumed. Every .dmf in the Deflemask/ (modland, 1,809) and
# Battle of the Bits (263) collections was fetched and its header read:
#    598 kept  -- SEGA Genesis  (system byte 0x02)
#     98 kept  -- SEGA Master System (system byte 0x03)
#    171 dropped -- corrupt: the deflate stream completes but the stored
#                   Adler-32 does not match, and the payload really is damaged
#                   (it desynchronises mid-parse). Furnace rejects these too.
#     11 dropped -- DMF versions 0x0D, 0x10 and 0x19-0x1B, for which DefleMask
#                   never published a spec; they desynchronise and are declined
#                   rather than mis-parsed.
#     57 dropped -- SEGA Genesis EXT.CH3 (system byte 0x42): splits FM channel 3
#                   into four independently-pitched operators, a different
#                   channel model that dmfcrplugin does not implement.
#
# The remaining DefleMask rows target Game Boy, PC Engine, Neo Geo, NES, C64 or
# Arcade and stay hidden in mas until those targets land. The unrelated
# X-Tracker "DDMF" .dmf rows are not affected by any of this -- libopenmpt plays
# them in both variants and they were never gated.
#
# Regenerate after a collection update with tools/dmfcheck (see its README):
# probe each file's system byte and DMF version, keep 0x02/0x03, 0x11-0x18, and
# a clean checksum.
