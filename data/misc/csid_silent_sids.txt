# SIDs that the cSID engine cannot make a sound with -- one HVSC-relative path
# per line. Used ONLY by the Mac App Store build, which has no VICE fallback.
#
# These are almost all RSIDs whose header play address is $0000: the tune
# installs its own IRQ/NMI handler and expects a real C64 (KERNAL banked in, CIA
# and raster running), which cSID does not emulate. The plus build plays them
# through VICE and is unaffected.
#
# MEASURED, not assumed. Every .sid in HVSC with play=$0000 was rendered through
# the same engine and the same 3s / peak>64 test the player uses at runtime, and
# a file is listed ONLY when EVERY subtune stayed silent:
#   3708 RSID play=$0000  ->  2363 wholly silent, 1242 wholly fine, 103 mixed
#    109 PSID play=$0000  ->    19 wholly silent,   90 fine
# So a blanket "hide every play=$0000 RSID" rule would have hidden 1345 files
# that play perfectly well. The mixed ones are deliberately NOT listed: they have
# playable subtunes, and the runtime probe skips the silent ones gracefully.
#
# Regenerate with scratchpad/sidprobe/probe (see the musplugin notes) after an
# HVSC update. Unlisted files are not a problem -- they simply fall back to that
# runtime probe.
