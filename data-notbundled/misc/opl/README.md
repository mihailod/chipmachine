# The OPL Archive

## Base URL
https://opl.wafflenet.com/vgm

## File format
All files are .vgm that are gzipped to .vgz

## Example song
https://opl.wafflenet.com/vgm/2a03fox/Snowgoons%20vs%20Acid.vgz

## Example path
Ad Lib, Inc/Johann Sebastian Bach - Flute Sonata in E-flat Major, II - Siciliano.vgz

## Notes
Path needs to be URI encoded when download URL is formed

The downloaded file needs to be first gunzipped, then renamed to vgm: .vgz -> .vgm
