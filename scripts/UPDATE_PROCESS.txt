the CSDb database serves two purposes:
Screenshots — artwork to display while a SID plays
Product→song linking — associating SID files with the demo/diskmag/collection that used them, so you can browse by release rather than by individual SID file
It does NOT provide any audio itself — all audio is HVSC SID files.
The flow is:
HVSC is indexed first — every SID path gets hashed and stored in pathMap
When CSDb is parsed, for each SID path in <Sids>:
So CSDb only enriches songs already in HVSC — it can't add new songs. If a SID path in CSDb doesn't exist in HVSC, it's logged and ignored. If it does exist, the CSDb entry provides the screenshot and groups the song under a named product (demo, diskmag, etc.).

  ──────
  ### 2. Files NOT USED to Build the Database

  These files exist in the  data/  directory but are never loaded or processed during the music database creation ( music.db  &
  index.dat  generation):

  #### Commented-Out Collections:

  • nsfe.txt : This is a NES Sound Format Extended index file.
  The NSFE database collection is commented out at lines 208-215 of db.lua.
  THIS WAS FIXED AND ENABLED!

  #### Plugin & Engine-Specific Files (Used at Playback Time, not DB Build Time):

X •  Songlengths.md5 : Utilized directly by the SID player engine to dynamically check HVSC song durations on demand during
  playback (via MD5 hashing), completely bypassed by the database parser.
X •  STIL.txt : The SID Tune Information List contains textual background information and comments for C64 tracks, queried by
  the player interface when a SID file is loaded.
- •  adplug.db : An internal binary database used solely by the  AdPlug  player plugin to handle OPL2/OPL3 (AdLib) metadata.
- •  hebios.bin : Emulation BIOS file utilized exclusively by the HEBIOS console sound emulator.
- •  sc68  /  sc68.cfg : The emulator engine configuration file and resources for SC68 (Atari ST) playback.

  #### Obsolete & System Files:

  •  OLDVICESonglengths.txt : Obsolete text file containing C64 track lengths for the old VICE emulators (scheduled for removal,
  completely ignored by database indexing).
  •  Bello.otf  /  Neutra.otf : System typography font files used to render the graphical UI.
  •  extractor.py : Python script used to fetch or process indexes, not loaded by C++ database builder.
  •  __pycache__  /  python_runtime  /  misc  /  c64  /  uade : Utility directories that house scripts, compilers, emulators,
  and assets.
